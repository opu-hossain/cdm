Core Download Manager

Download with cdm

Right-click an HTTP or HTTPS link or page and choose its Download with cdm item. Review the destination in the cdm popup and confirm to start.

Menu offers open a confirmation popup regardless of file size or type. Downloading a page saves its URL response; it does not make an offline copy of its images and other resources.

Automatic interception filters

Zero minimum and empty lists intercept all supported downloads. When a minimum is set, unknown sizes stay in the browser. Deny lists win; matching either populated allow list permits a file. Settings sync through your browser.

Use comma-separated lists, up to 64 entries each. MIME types support type/* and */*.

Use comma-separated ASCII/punycode hostnames, up to 64. A *. prefix matches the base hostname and its subdomains. Exclusions affect automatic interception only; explicit menu choices remain available.

Off by default. Enabling requests permission to observe HTTP(S) response headers on all sites. This collects up to 64 media candidates in extension memory for ten minutes; it never opens download popups automatically. Browser-session cookies still require the separate site-specific toggle.

Detected media

Refresh after playing a video. Only direct video files and HLS/DASH manifests appear here. YouTube formats appear in the in-player picker. Select a candidate to review in cdm. Manifests are retained ahead of video segments. Detection excludes private browsing and excluded sites; an explicit selection bypasses download filters.

Disabling detection clears candidates. Granted browser permissions remain available for the site-specific session toggle; revoke them through your browser.

Browser session

Browser session sharing is off by default. Click the extension's toolbar button on a site to enable it for that site and grant optional permissions. Cookies may authenticate as you. Click again to turn it off. Restarting the extension resets the toggle; private browsing never supplies session data.

The cdm popup indicates when cookies or request headers are included. Cancel discards the offer. Captured values stay in daemon memory and are cleared when the download ends. A daemon restart needs a fresh browser offer.
